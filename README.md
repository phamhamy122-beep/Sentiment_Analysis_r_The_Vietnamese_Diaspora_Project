# Sentiment Analysis on YouTube comments of Vietnamese Online Diaspora Communities
This sentiment analysis is part of a study investigating emerging online communities of Vietnamese people living overseas. This analysis utilizes the ‘syuzhet’ package in the R language to derive the proportions of eight primary sentiments within textual data.   
## Description of the project
Tech used: Netlytic.org, R
This analysis is part of the project investigating Vietnamese online diaspora communities, conducted during my second Lab Rotation. The objective of the project is to analyze how two Vietnamese online communities (Vietnamese-French and Vietnamese-German) destigmatize their Việt Kiều identities through activities on YouTube. The study consists of two parts: sentiment analysis and multimodal discourse analysis. 
The textual data was scraped from YouTube using [Netlytics.org](https://netlytic.org/) (which was replaced by [Communalytic.org](https://communalytic.org/) in 2024), capturing information such as comments, posting dates, replies and so on. These comments were then imported into RStudio for further analysis. 
The ‘syuzhet’ package was utilized in RStudio to analyze sentiments within the textual data. This package is commonly used for social media texts analysis and provides tools for processing multiple languages. It can derive polarities (negative vs. positive) as well as eight primary sentiments: anger, anticipation, disgust, fear, joy, sadness, surprise and trust. 
The package also provides tools for visualizing sentiments across the corpus. These visualizations for both communities were also provided in the repository. 
In conclusion, the sentiment analysis obtained similar patterns in both communities. Trust accounted for the highest proportion in both groups, while negative sentiments such as ‘anger’ and ‘disgust’, and positive engagement such as ‘anticipation’ remained at the bottom. Notably, the Vietnamese-French community showed a high proportion of ‘joy’. These patterns suggest that, despite the historically controversial identities associated with the Việt Kiều, these online communities were built on a foundation of development, trust and mutual understanding. 
Using the ‘syuzhet’ toolkit, I was also able to further investigate further the context of these sentiments and discussions by identifying comments with the highest engagement responses and those with the highest sentiment scores. 
The study was accepted for presentation at ECREA 2024 (the largest annual conference for the communication science research community in Europe) and is currently being finalized for publication. 
## Limitations and Improvements
-	**Methodological Constraints**: The study utilizes a pre-built package for analysis, which is a convenient approach for researchers with limited coding experience. However, this method has its limitations; for instance, the researcher cannot easily inspect or adjust the underlying algorithm used to derive sentiment scores from the corpus.  
-	**Data Quality and Language Processing**: social media text is often characterized by typos, noise, slang, and special characters, all of which can significantly skew analysis results. Furthermore, the package lacks specialized tools for preprocessing the Vietnamese language. Consequently, the analysis may not accurately categorize or score words based on the provided lexicons. A key recommendation for future iterations is to implement rigorous, language-specific preprocessing steps to improve data accuracy.
